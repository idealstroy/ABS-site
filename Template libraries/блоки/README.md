# Каталог блоков для сайта найма водителей спецтехники

Этот каталог нужен, чтобы страницы собирались из заранее понятных секций, а не придумывались заново каждый раз.

## Общие правила
- Используем только 12-колоночную сетку.
- Один экран = одна главная мысль.
- На каждом экране должен быть понятный следующий шаг.
- Сильные визуальные акценты делаем через фото техники, иконки и форму.
- Тексты короткие, прикладные, без лишней воды.

## Базовый порядок страницы
1. Hero
2. Преимущества с иконками
3. Блок с фото техники или водителя
4. Открытая форма заявки
5. Шаги работы
6. Блок доверия и документов
7. FAQ
8. Контакты и карта

## 1. Hero с фото
Когда использовать:
- Главная страница
- Посадочные страницы под конкретную вакансию

Состав:
- Большой заголовок
- Подзаголовок
- 1-2 CTA-кнопки
- Фото строительной техники, кабины, водителя или объекта
- 2-4 цифры/факта

Рекомендация по виду:
- Слева текст, справа изображение
- На мобильном сначала текст, потом изображение

## 2. Hero без фото
Когда использовать:
- Узкие посадочные страницы
- Сильный акцент на форме или оффере

Состав:
- Заголовок
- Описание
- Короткий список выгод
- CTA
- Небольшой блок доверия

## 3. Преимущества с иконками
Когда использовать:
- После hero
- Для перечисления причин выбрать именно этот сервис

Состав:
- Заголовок секции
- 3-6 карточек
- В каждой карточке одна иконка, один тезис, одно пояснение

Темы карточек:
- Быстрый выход на смену
- Проверка документов
- Работа по объектам
- Стабильные заказы
- Поддержка и связь
- Безопасность

## 4. Блок с фото и текстом
Когда использовать:
- Для описания техники, условий работы, географии

Состав:
- Большое изображение
- Текстовый блок
- Список из 3-5 пунктов
- Кнопка действия

Правило:
- Фото всегда должно объяснять смысл блока, а не просто быть декоративным.

## 5. Карточки техники
Когда использовать:
- Если показываем типы спецтехники
- Если нужны направления работы

Состав карточки:
- Фото техники
- Название
- 2-4 характеристики
- Метка: объект, смена, регион, категория
- CTA

Примеры карточек:
- Самосвалы
- Экскаваторы
- Погрузчики
- Автокраны
- Бульдозеры

## 6. Карточки водителя
Когда использовать:
- Для вакансий или профилей кандидатов

Состав:
- Фото или аватар
- Категория прав
- Опыт
- График
- Регион
- Кнопка отклика

## 7. Открытая форма заявки
Когда использовать:
- После hero
- В середине страницы
- Внизу страницы

Состав:
- Заголовок
- Короткое пояснение
- Имя
- Телефон
- Комментарий
- Кнопка отправки
- Подпись о согласии

Правило:
- Форма должна быть видимой сразу, без скрытия в модальном окне.
- Если задача горячая, делаем форму широкой и заметной.

## 8. Быстрая форма в строку
Когда использовать:
- Для короткого CTA-блока
- Для захвата заявки на мобильных и desktop

Состав:
- Телефон
- Имя
- Кнопка

## 9. Шаги работы
Когда использовать:
- Чтобы показать путь кандидата

Состав:
- 3-5 шагов
- Номер шага
- Заголовок
- Короткий текст

Пример:
- Оставляете заявку
- Уточняем опыт и категорию
- Согласуем объект и график
- Выходите на смену

## 10. Блок доверия
Когда использовать:
- После формы
- Перед финальным CTA

Состав:
- Документы
- Допуски
- Опыт работы
- Гарантии
- Значки или иконки

Темы:
- Проверка документов
- Официальное оформление
- Безопасность
- Связь с менеджером

## 11. Цифры и факты
Когда использовать:
- Для усиления доверия

Состав:
- 3-4 числовых показателя
- Короткое пояснение под каждым

Примеры:
- лет на рынке
- объектов в работе
- заявок в месяц
- часов до ответа

## 12. FAQ
Когда использовать:
- В нижней части страницы

Состав:
- 5-8 вопросов
- Аккордеон

Темы:
- Какие категории прав нужны
- Можно ли без опыта
- Какие объекты доступны
- Как быстро дают ответ
- Какие документы нужны

## 13. Контакты
Когда использовать:
- В конце страницы
- Как финальная точка маршрута

Состав:
- Телефон
- Мессенджеры
- Адрес
- Карта
- Режим работы

## 14. Финальный CTA
Когда использовать:
- Последний блок любой посадочной страницы

Состав:
- Короткий сильный оффер
- Кнопка
- Телефон
- Минимум отвлекающих элементов

## 15. Форматы изображений
- Hero: широкое горизонтальное фото
- Карточки техники: 4:3 или 1:1
- Карточки водителя: портрет или нейтральный аватар
- Контакты: скрин карты или встроенная карта

## 16. Иконки
- Берем только из подготовленной папки иконок проекта.
- Не смешиваем много визуальных стилей.
- Для блоков используем одну логику: одна иконка = одна мысль.

## 17. Готовая схема для сборки страницы
- Hero с фото
- Преимущества с иконками
- Техника или условия работы
- Открытая форма
- Шаги
- Доверие
- FAQ
- Контакты

Если нужна новая страница, сначала выбираем блоки из этого каталога, а уже потом наполняем их контентом.
