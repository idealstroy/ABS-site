# Библиотека булетов

Для булетов используется локальная копия [Tabler Icons](./tabler-icons) — SVG-библиотека с лицензией MIT.

Основной набор находится в папке `tabler-icons/icons/outline`.

## Рекомендуемые варианты

| Назначение | Файл |
| --- | --- |
| Подтвержденное преимущество | `circle-check.svg` |
| Короткий пункт списка | `check.svg` |
| Список проверок | `checklist.svg` |
| Указатель на действие | `arrow-right.svg` |
| Указатель в круге | `circle-arrow-right.svg` |
| Маркер-точка | `point.svg` |
| Документы и проверка | `file-check.svg` |
| Безопасность и проверка | `shield-check.svg` |

Использование: сохраняем один стиль в пределах блока, подключаем SVG локально и задаем цвет только из фирменной палитры АБС. Для большинства коммерческих списков на сайте использовать `circle-check.svg` или `check.svg`.
