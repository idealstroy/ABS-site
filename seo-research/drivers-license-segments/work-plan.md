## Дизайн-бриф

Новый тип блока — «Паспорт транспортной задачи»: в одной композиции крупный маркер сегмента, короткое описание техники и колонка требований для заявки. Для B — четыре компактных текстовых направления в Bootstrap-сетке; для страниц специалистов — узкий паспорт с требованиями конкретной техники, без повторения общего текста B.

Использовать действующие Open Sans, фирменные цвета, Bootstrap, радиус карточек 16px и CTA 10px. Никаких изменений header/footer, hero, главной или альтернативной главной. Не создавать декоративные кнопки из обозначений категорий. Мобильная версия — одна колонка, без горизонтальной прокрутки. Это бриф, ещё не реализованный дизайн.

## Нормативная проверка

Статья 25 Федерального закона №196-ФЗ перечисляет CE и DE как категории. Требование C + D не эквивалентно CE для грузового состава. Исходные названия C + E / D + E в таблице выше оставлены для прослеживаемости согласованного плана, а не как подтверждённое описание законодательства.

Источник, проверен 07.10.2026: https://www.consultant.ru/document/cons_doc_LAW_8585/1e24735df982c4fb8bf865fe29270095749ba3bc/

В новых блоках используются корректные обозначения CE и DE. Для тягача явно указано, что C + D не заменяют CE. Дополнительные внутренние требования компании не выдумывались.
