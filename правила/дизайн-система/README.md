# Дизайн-система сайта найма водителей спецтехники

Основа системы: Bootstrap 5.3. Мы используем его как единый каркас для сетки, типографики, кнопок, карточек, форм и адаптивности.

## Принципы
- Надежность, техника, безопасность.
- Минимум декоративного шума.
- Крупные заголовки, короткие смысловые блоки, понятные CTA.
- Один акцентный стиль для всех страниц.

## Основа
- Сетка: [`../bootstrap-5-grid-12-columns.html`](../bootstrap-5-grid-12-columns.html)
- Иконки: [`../иконки/bootstrap-icons-repo/icons`](../иконки/bootstrap-icons-repo/icons)
- Подборка иконок для этого проекта: [`../иконки/bootstrap-icons-construction/index.md`](../иконки/bootstrap-icons-construction/index.md)

## Цвета
- Primary: `#E03B32`
- Secondary: `#777777`
- Surface: `#F6F7F8`
- Text: `#3D4A61`
- Success: `#27AE37`

## Типографика
- Заголовки: `Manrope`, `font-weight: 700`
- Основной текст: `Inter`, `font-weight: 400`
- Межстрочный интервал: плотный, но не сжатый
- Используем:
  - `h1` для главных экранов
  - `h2` для секций
  - `h3` для карточек и подзаголовков
  - `.lead` для вводного текста

## Сетка и ритм
- Базовый шаг: `8px`
- Скругление: `16px` на карточках, `12px` на мелких элементах
- Тени: мягкие, без сильного размытия
- Отступы между крупными блоками: `64-96px` на desktop, `40-64px` на mobile

## Кнопки
- Главная кнопка: заполненная `primary`
- Вторичная кнопка: контурная или `secondary`
- Третичная кнопка: text/link style
- На странице не больше 2 заметных CTA одного уровня

## Карточки
- Белый фон
- Тонкая рамка
- Иконка сверху или слева
- Один смысл на карточку

## Иконки
- Используем только иконки из подготовки для этого проекта.
- На странице держим один стиль иконок, без смешивания разных наборов.
- Предпочтительные темы:
  - техника
  - водитель
  - документы
  - безопасность
  - геолокация
  - время

## Блоки страниц
- Первый экран: оффер, преимущества, CTA, фото техники или водителя.
- Доказательства: цифры, кейсы, документы, допуски.
- Процесс: 3-5 шагов.
- Контакты: телефон, форма, карта, режим работы.

## Цветовой режим
- По умолчанию светлая тема.
- Если нужен темный блок, используем `data-bs-theme="dark"` только точечно.

## Правило для верстки
Любая новая страница должна собираться из этих же токенов, той же сетки и тех же иконок. Это держит сайт цельным и без визуального распада.
