# Сайт АБС

Техническая основа сайта собирает обычные HTML, CSS, JS и PHP-файлы для размещения на Beget. Сборка не использует внешний JavaScript-фреймворк и не требует Node.js на хостинге.

## Команды

- `npm run build` - собрать технический каркас в `dist`.
- `npm start` - собрать проект и запустить локальный PHP-сервер на `http://127.0.0.1:8080/`.
- `npm run check` - проверить DOM, внутренние маршруты, ассеты, цвета, шрифт и Bootstrap-сетку.
- `npm test` - выполнить сборку, технические проверки и полный тест формы в локальном безопасном режиме.

## Важно

Главная страница собирается из `src/data/pages/home.json` и `src/templates/home.html` в `dist/index.html`. Согласованный контент альтернативной главной перенесён на `/`; отдельный дубль прототипа удалён. Общий шаблон `src/templates/base.html` содержит счётчики, код верификации и подключения сторонних скриптов. Формы и события аналитики используют прежний тип страницы `home`.

Технические шаблоны в `dist/_prototype` закрыты от индексации. Главная использует canonical `https://abs-engineer.ru/` и разрешена к индексации.

Подробное описание находится в `docs/technical-foundation.md`.
# Деплой по SSH

Для загрузки финальной сборки на Beget используйте одну команду:

```powershell
npm run deploy
```

Деплой повторяет схему ПТО Онлайн: серверный бэкап → локальная сборка и проверка → передача полного архива через SSH/SCP → обновление ресурсов и HTML → проверка сайта → откат при ошибке. Дополнительных установок нет.

Подключение: `idealstroy_dev@idealstroy.beget.tech`, каталог `/home/i/idealstroy/abs-engineer.ru/public_html`. Пароль вводится в терминале и не сохраняется. Для ACL Beget точечно адаптированы параметры копирования файлов; chmod существующих рабочих каталогов исключён. Владельцы заменяемых файлов могут измениться на пользователя деплоя, доступ новых файлов зависит от наследуемых ACL целевых каталогов. Публикация с этой адаптацией на хостинге пока не проверена.

Только локальная проверка: `npm run deploy -- -ValidateOnly`. Проверка передачи архива без публикации: `npm run deploy -- -UploadOnly`. Полный запуск `npm run deploy` не запрашивает подтверждение DEPLOY. Старые параметры CheckOnly/PlanOnly больше не используются. Подробности: [схема деплоя](docs/safe-deployment.md).
