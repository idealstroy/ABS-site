# Сайт АБС

Техническая основа сайта собирает обычные HTML, CSS, JS и PHP-файлы для размещения на Beget. Сборка не использует внешний JavaScript-фреймворк и не требует Node.js на хостинге.

## Команды

- `npm run build` - собрать технический каркас в `dist`.
- `npm start` - собрать проект и открыть локальный PHP-сервер на `http://localhost:8080/_prototype/home/`.
- `npm run check` - проверить DOM, внутренние маршруты, ассеты, цвета, шрифт и Bootstrap-сетку.
- `npm test` - выполнить сборку, технические проверки и полный тест формы в локальном безопасном режиме.

## Важно

Корневые `index.html`, `styles.css`, `request.html` и `send-request.php` являются ранее созданным прототипом главной страницы. Они сохранены как исходный материал и не входят в новую сборку. Коммерческие страницы будут переноситься в `src/data/pages` только в соответствующих пунктах дорожной карты.

Технические шаблоны в `dist/_prototype` закрыты от индексации. До отдельного релизного решения файл `robots.txt` запрещает индексацию всей сборки.

Подробное описание находится в `docs/technical-foundation.md`.
# Деплой по SSH

Для загрузки финальной сборки на Beget используйте одну команду:

```powershell
npm run deploy
```

При первом запуске сценарий попросит полный путь к каталогу сайта на сервере и сохранит только этот путь в локальном `.deploy-config.json`. Затем он запускает `npm test` и загружает только содержимое `dist` на `idealstroy.beget.tech` от имени `idealstroy_1` через `scp`. Пароль запрашивается OpenSSH при каждом деплое и не сохраняется в файлах, переменных окружения или Git.

`RemotePath` должен быть существующим каталогом сайта на сервере. Укажите фактический путь из панели Beget или результат команды `pwd` после входа по SSH. Чтобы изменить сохранённый путь, удалите локальный `.deploy-config.json` и снова выполните `npm run deploy`.
